# Part 2 Testing Notes

## Static checks completed

The project was checked programmatically for:
- `style.css` linked on all five HTML pages.
- Navigation present on all five pages.
- Forms present on the enquiry and contact pages.
- Images containing alternative text.
- Local HTML navigation links pointing to existing pages.
- Flexbox and CSS Grid rules in the stylesheet.
- Tablet and mobile media-query breakpoints.
- Relative CSS units including `%`, `rem` and `em`.
- Responsive image attributes using `srcset` and `sizes`.

## Browser evidence still required

The assessment brief requires screenshot evidence of the website at desktop, tablet and mobile sizes. Those screenshots should be captured after opening the completed project in a normal browser and added to the README. Only actual browser tests should be reported as visual testing evidence.
